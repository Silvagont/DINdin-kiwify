TRILHA 02 · INICIANTE

Aprenda CSS do zero

CSS define a aparência das páginas: cores, fontes, espaços, alinhamento e como os elementos se organizam em diferentes telas.

O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. Ele aplica regras visuais aos elementos HTML.

1. Como uma regra CSS funciona?

Uma regra CSS tem um seletor e um bloco de declarações. O seletor indica quais elementos serão afetados. Cada declaração combina uma propriedade com um valor.

style.css
h1 {
  color: #176344;
  font-size: 2rem;
}

p {
  line-height: 1.7;
}

Neste exemplo, todos os títulos h1 recebem uma cor verde e um tamanho de fonte. Os parágrafos recebem maior espaçamento entre linhas.

2. Layout responsivo

Um layout responsivo se adapta a diferentes larguras de tela. CSS Grid, Flexbox e media queries ajudam a organizar o conteúdo para computadores, tablets e celulares.

Experimente

Altere o valor de gap em um layout de cartões e observe o espaço entre eles. Depois reduza a largura da janela do navegador.
