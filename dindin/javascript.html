TRILHA 03 · INICIANTE

Aprenda JavaScript do zero

JavaScript permite que uma página responda a ações, atualize informações e ofereça experiências interativas.

O que é JavaScript?

É uma linguagem de programação muito usada para adicionar comportamento a páginas web. Com ela, podemos reagir a cliques, validar formulários e atualizar o conteúdo sem recarregar a página inteira.

1. Variáveis e valores

Uma variável permite guardar um valor que será usado pelo programa. Use const quando não pretende reatribuir a variável e let quando o valor poderá mudar.

script.js
const nome = "Ana";
let pontos = 0;

pontos = pontos + 1;
console.log(nome);
console.log(pontos);

O exemplo guarda um nome e aumenta a quantidade de pontos em um. O método console.log mostra valores no console do navegador.

2. Responder a um clique

Um evento representa algo que acontece, como um clique. O método addEventListener permite definir o que deve acontecer quando esse evento ocorre.

Exemplo
const botao = document.querySelector("#meuBotao");

botao.addEventListener("click", () => {
  console.log("Botão clicado!");
});

Para funcionar, o HTML precisa ter um elemento com id="meuBotao". O seletor deve corresponder ao identificador do elemento.
