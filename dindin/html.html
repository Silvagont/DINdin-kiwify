TRILHA 01 · INICIANTE

Aprenda HTML do zero

HTML é a base que organiza o conteúdo de uma página web. Nesta trilha, você vai aprender a estruturar páginas com elementos claros e semânticos.

O que é HTML?

HTML significa HyperText Markup Language, ou Linguagem de Marcação de Hipertexto. Ele descreve a estrutura do conteúdo que o navegador apresenta. HTML não é uma linguagem de programação: é uma linguagem de marcação.

1. A estrutura básica de um documento

Uma página HTML começa com uma declaração do tipo de documento, seguida pelo elemento html. Dentro dele, usamos head para informações sobre a página e body para o conteúdo exibido.

index.html
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <title>Minha página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Esta é minha primeira página.</p>
  </body>
</html>
  • <h1> marca o título principal.
  • <p> marca um parágrafo.
  • <title> define o título exibido na aba do navegador.
  • lang="pt-BR" indica o idioma principal do documento.

2. Títulos e parágrafos

Use títulos de h1 a h6 de acordo com a hierarquia do conteúdo, não apenas pelo tamanho visual. Use p para parágrafos. Cada elemento tem um significado, o que ajuda leitores, navegadores e tecnologias assistivas.

Experimente

Altere o texto dentro de <h1> e de <p>, salve o arquivo e atualize o navegador. O texto muda sem precisar alterar o CSS.
