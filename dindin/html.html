TRILHA 01 · INICIANTE

Aprenda HTML do zero

Aprenda a criar a estrutura de páginas para a internet, usando títulos, parágrafos, imagens, links e outros elementos.

O que é HTML?

HTML significa HyperText Markup Language, ou Linguagem de Marcação de HiperTexto. Ele organiza o conteúdo de uma página para que o navegador saiba o que apresentar.

1. A estrutura básica de uma página

Uma página HTML começa com uma estrutura que informa ao navegador qual é o tipo de documento, define o idioma, configura os caracteres e organiza o conteúdo.

index.html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Minha página</title>
</head>
<body>
  <h1>Olá, mundo!</h1>
  <p>Minha primeira página.</p>
</body>
</html>

Entenda as partes

<head>: contém informações e configurações da página.

<title>: define o título mostrado na aba do navegador.

<body>: contém o conteúdo visível da página.

<h1>: representa o título principal.

<p>: representa um parágrafo.

2. Títulos, links e imagens

O HTML possui elementos para organizar diferentes tipos de conteúdo. Veja alguns exemplos:

Exemplo de elementos
<h1>Meu primeiro site</h1>

<h2>Sobre mim</h2>

<p>Estou aprendendo a programar.</p>

<a href="https://example.com">
  Visitar um site
</a>

<img src="foto.jpg" alt="Descrição da foto">

Os títulos ajudam a organizar o conteúdo. Os links levam a outras páginas, e as imagens acrescentam conteúdo visual. O atributo alt descreve a imagem para quem utiliza leitores de tela e também quando ela não carrega.

Desafio prático

Crie uma página com seu título, um parágrafo contando o que você está aprendendo e um link para um site que você gosta.
